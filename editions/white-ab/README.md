# ChartUI ホワイトアウト版 AB — サトシを探せ版（v0.1）

白い紙と墨と一本の赤だけで描く、3 つの場面の小さなゲーム。依存するものはなく、クローンして `index.html` を開けばすぐ遊べる。

```bash
git clone <この版のリポジトリ>
```

`index.html` をブラウザで開く（サーバーは要らない）。うまく開けないときだけ、このフォルダーで次を実行して http://localhost:8000 を開く。

```bash
python3 -m http.server 8000
```

## 遊び方

1. **OP**：aviator の「リトル」が六角形の島（Dual の 6 つのポート）を一周し、8 aviator に着地。裏返されたカードが 1 枚置かれる。（クリック／Enter で進む）
2. **回想 — LAB**：ガラスのカプセルに 3 体。顔は描かれず、余白が顔になっている。ペン（マウス・指）で 1 体ずつなぞると、署名の指紋（SHA-256 の先頭と emoji 20 進数）が浮かぶ。カードと同じ指紋の 1 体を選ぶ（1・2・3 キー、またはダブルクリック）。顔は見えないまま、鍵だけが確かめられる。
3. **デッキ**：ファミコン型のポケットを、デッキの差し込み口へドラッグ（または Enter）。カードがめくれ、吊るされた男が現れ、ゆっくり正位置へ回る。「止まって、逆さに見る。ロープは、落ちるためではなく、降りるための道具。」

R でいつでも最初から。動きを減らす設定のときは、短く静かに進む。

## この版の約束

- 色：白 #ffffff、墨 #1f1f1f、赤 #c8001a、補助の灰 #57534e（どれも白に対して 4.5:1 以上）。
- 登場する鍵・署名・残高はすべて架空。実在の人物（サトシ・ナカモトの正体を含む）を特定するものではない。署名が示すのは「この鍵で署名された」ことだけで、誰がその鍵を持っているかではない。
