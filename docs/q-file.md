# .q ファイル（量子への願いの記録）

量子補完計画の最初の形。スピン LAB の IBM チャレンジの欄の右上にある `{:}` から入る隠しゲームで作る。

## 形

記号 `“”= () => {}{({:}{:})}` をそのまま形にした：空の始まり、何も受け取らない関数、空のオブジェクト、そして括弧の中の 2 つの枠 `{:}{:}` ＝ 球 a と球 b。観測前は `a="()" b="()"`、観測後は落ちた区画 `"(7)"`。`next` が前の願いを指すので、願いは鎖になる（git のように）。

```json
{
  "q": "1",
  "glyph": "“”= () => {}{({:}{:})}",
  "founders": { "emoji進数": "オープンソース", "emoji20進数": "オープンソース++" },
  "when": "2026-11-12T12:38:08.532Z",
  "where": "図書館の入口",
  "quantum": { "problem": "hair", "source": "hair-local-statevector", "backend": "…", "result_sha256": "…" },
  "wish": "前髪がきれいに分かれますように",
  "a": "(4)", "b": "(4)", "angles": { "a": 0, "b": 1047 },
  "rhythm": { "bpm": 100, "steps": "xx.xxx.xxx......", "emoji": "🌘🌒🎲🌸", "score": 560, "offsets_ms": [0, 12, -30] },
  "next": "🌒🌷🌷…（前の .q の名前）",
  "sig": { "alg": "Ed25519", "signer": "…", "sig": "…" }
}
```

- **名前**：`sig` を除いた中身を `.meshmeta` v2 と同じ正規化（NFC＋JCS、数は整数だけ）にして SHA-256 を取り、emoji 20 進数で書いたもの。
- **emoji 20 進数**：`🌑🌒🌓🌔🌕🌖🌗🌘🌸🌼🌻🌹🌷🐟🐠🐡🍬🍭🎲🎯`（🌑 が 0）。どれも 1 文字コードの絵文字だけ（U+FE0F の揺れがない）。先頭のゼロのバイトは 🌑 で残す。
- **いつ・どこで・どの量子に**：時刻、場所の言葉、使った量子の結果（問題・どこで測ったか・結果の SHA-256）。
- **リズム**：100 BPM の 4 拍に 8 回叩き、16 分音符の格子に合わせる（PERFECT ±25 ms / GREAT ±50 / GOOD ±90）。並び（`x` と `.`）とずれ（ms）を署名の中身に入れる。リズムは「その人らしさ」の印で、合言葉ではない。守りは Ed25519 の署名。
- **ルーレット**：22 区画。量子の結果の分布で重みづけし（結果 k → 区画 k mod 22）、ブラウザの乱数で引く。願いに記号 `“”= () => {}{({:}{:})}` を書くと 2 球モード：ダイヤルの角度 θa・θb の差で、2 球が同じ区画に落ちる確率が cos²((θa−θb)/2)（ベル対を 2 つの向きで測ったときと同じ式）。それ以外は向かい合わせ（11 区画先）。角度はミリラジアンの整数で記録。
- **鍵**：ブラウザごとに 1 つ、取り出せない形で IndexedDB に置く。
- **取引の続き**：落ちた区画 mod 4 の車（A〜D）のカメラで、ORACLE のレース中継に戻る（`/oracle-api/race?focus=n`）。
