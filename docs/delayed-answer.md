# 先行と後攻：答えが後から届く問題（Cure-API とソースの見直し）

最終更新：2026-11-12。「答えが届くのが後になる」ことが、リポジトリのどこにどう現れているかの整理。

| 場所 | 何が後から届くか | いまの扱い |
|---|---|---|
| CELL CONVERGENCE // DIAGNOSTIC（`components/cure/CellConvergence.tsx`） | 最後の EX セルが治る瞬間（tail） | 治るのは記憶のない待ち時間（率 λ の指数分布）。すでに何秒待っても、残りの期待値は 1/λ のまま。retest で何度も測ると、1 回ごとの tail は大きくばらつき、平均だけが 1/λ に近づく（試験：λ = 0.3 で 0.4 s・7.6 s・1.6 s、平均 3.2 s、理論 3.3 s） |
| プロンプトチェス（`lib/promptChess.ts`） | 相手の手 | 先手・後手をなくし、両方の手を同時に走らせる。同じ区画は衝突して両方戻る。先に動いた方が得をする構造そのものを消した |
| アクティビスト双六（`lib/activistSugoroku.ts`） | 他の車の手 | `git push` で全員同時。同じマスは merge conflict |
| IBM Quantum チャレンジ（`quantum/`） | 実機の測定結果 | 順番待ちのあとに届く。ゲームでは「未来からの手紙」に見立てるだけで、過去は書き換えない（量子でも過去へ情報は送れない） |
| `.q` の鎖（`lib/quantumWish.ts`） | 次の願い | 後の記録が前の記録の名前（`next`）を持つ。前の記録は後の記録を知らない |
| 昇格の案（`docs/` の議論） | 何に成るか（2 量子ビット：00 クイーン・01 ルーク・10 ビショップ・11 ナイト） | 答えが届くまで「昇格中（未定）」で盤に残す案 |

## デザインの規則として

- 待ち時間が記憶のない場面では、「あと何秒」と言い切らない。「残りの期待値 ≈ 1/λ（待っても変わらない）」と見せる。
- 同時に動く仕組み（同時走行・git push）は、先手の得を消すための道具として使う。衝突の扱いを必ず決めておく。
- 後から届く答えは、届くまで「未定」の状態を画面に持つ。届いた答えで過去の表示を書き換えない。

## 肖像アイコンの遺伝子（`lib/designerGene.ts`）

- ♚ KING・♛ QUEEN・♞ KNIGHT・♟ PAGE の肖像は、それぞれのシミュレーションの値から作る 7 つの遺伝子座（shell・pull・swirl・jitter・hue・weight・crown）で描く。各座は A〜D の対立遺伝子（値の範囲の 4 分割）と、元の値を持つ。
- EX が 0 になった瞬間（風船が上がる）が誕生。細胞の数に比例して選んだ 2 つの役から、座ごとにどちらかを受け継ぎ、まれに隣の対立遺伝子へ変異する。同じ遺伝子は必ず同じ顔になる。名前は emoji 20 進数の 4 文字。
- アイコンのための架空の遺伝子で、生物学ではない。
