# .meshmeta

3D メッシュ（STL）の「どの三角形が、ファイルの何バイト目にあるか」を絵文字のポインター（⏸️ 開始位置・▶️ 長さ）で指し、署名と Merkle 証明で改ざんを見つけられるようにする、ChartUI のファイル形式です。

- v1：部品分け、品質 q = 2r/R の良い三角形 A〜D、絵文字のバイト位置ポインター、Ed25519 署名（`mesh_meta.py`、`lib/meshMeta.ts`）。
- v2：RFC 8785（JCS）の正規化、署名の配列、三角形ごとの Keccak-256 Merkle 木と、ポインターごとの証明（`meshmeta_v2.py`、`lib/meshMetaV2.ts`、仕様は [meshmeta-v2.md](meshmeta-v2.md)）。
- 試す：メッシュ LAB（`/lab/mesh`）の「.meshmeta v2 の検証」で、総合・STL の SHA-256・Merkle 根・各ポインター・署名が緑（正しい）か赤（おかしい）で出ます。改ざんのボタンで、何が赤になるかを確かめられます。
- 確かめる：`python -m pytest`（Python）と `npm run test:meshmeta`（TS が Python の固定データをバイト単位で再現するか）。
- パッケージ：`pip install cure-oracle`（`cure meshmeta` / `cure verify`）、`npm install chartui`（`meshmeta`・`meshmeta2`）。

## 何に使うか

- **3D の生け花作品の制作と採点**：作品のメッシュを部品（花・枝・葉・器）に分け、部品ごとの良い三角形 A〜D と品質の値を記録する。採点の基準（たとえば部品の数、形の整い方、空間の使い方）を決めるときの、解析のもとデータにする。署名があれば「採点したときの作品」と「いまのファイル」が同じであることを示せる。
- **個性的なヘアスタイルの保存**：髪型のメッシュと、その特徴を指すポインターを保存し、VR / MR の世界へ持っていく。Merkle 証明があれば、ファイル全体を渡さなくても、特定の部分（前髪の三角形など）が本物であることを示せる。

## 未完了のタスク（終わるまでここに残す）

1. テストネットに、小さな検証用のコントラクトを置く（Merkle 根の登録と、三角形 1 個の証明の検証だけ）。ウォレットとテスト用の資金の準備が必要です。
2. ブラウザのウォレットで、EIP-712 の署名を `signatures` に足す。

状態：どちらも未着手（2026-11-12）。v2 の葉と節点は OpenZeppelin の `MerkleProof` と同じ形に設計してあり（仕様の「ハッシュと Merkle 木」）、EIP-712 は `signatures` の予約名として場所を空けてある。

おすすめのテストネット（2026 年半ばの情報。使う前に各公式の案内で確認）：
- **Sepolia**（イーサリアム本体のテストネット）を第一候補にする。アプリとコントラクトの開発向けの標準で、OpenZeppelin の `MerkleProof` やブロックエクスプローラーでの検証がそのまま使える。Holesky は終了し、Hoodi はバリデーター向けなので、アプリの試験には Sepolia。
- 安く何度も試したい、またはパスキー（P-256）の署名も試したいときは、L2 のテストネット（Base Sepolia、OP Sepolia、Arbitrum Sepolia など）。
- テスト用の ETH は蛇口（faucet）でもらう。多くの蛇口はアカウント登録や、本番のアドレスに少額の残高があることを条件にしている。テストネットの鍵は、本番の資産を持つウォレットと分ける。

## 注意

- 署名は「誰が、この内容を確かに出したか」を示すだけで、作品の良し悪しや本人の権利までは示さない。人物に似せた髪型や顔のメッシュを扱うときは、本人の同意を確かめる。
- LAB の署名の鍵は、ページを開くたびにブラウザの中で作る試験用のもの。本番で使う鍵は別に管理する。
