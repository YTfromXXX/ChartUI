MENTE RESEARCH VOL.7 · A2 LINE
Line Machine：約2500年前のエジプト・ギリシャ・ローマで使用。木石板に水平線を引き、骨や象牙の球を置いて計算。ヨーロッパでは17世紀まで継続使用され、後にメタルジェトンに移行。最重要の発見：「水平基準線×離散位置」という記号構造がHollerithのパンチカードに直接継承されている。XV空間ではtheta文脈アーカイブとして機能。
