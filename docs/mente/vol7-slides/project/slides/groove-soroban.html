Grooved Soroban（溝型算盤）：ローマ帝国で使用された物理的な溝に珠を収めた計算板。溝がチャネルを定義し、珠の位置が値を決定する。重要な特性：溝という「物理的制約」が十進法を強制する。これはXV空間のα波制約経路と構造的に同型——α波はゆったりとした周期的制約として機能し、テンポラルグリッドの骨格を形成する。groove.beadsは8ビット配列で符号化される。
