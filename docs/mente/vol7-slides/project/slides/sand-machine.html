Sand Machine：メソポタミアで約3000〜4000年前に使われた最古の計算法。地面や砂に引いた線の上に石を置く。これはソロバンの直接の起源とされる。パース記号論で分析すると：石の位置が記号体、数量が対象、計算者の数理認識が解釈項。XV空間ではδ波の基底刻印として機能し、body_snapshotのsand.delta_densityフィールドに符号化される。
