# ストイックのプロフィール（v0.1・2026-11-13）

「イーサリアムの黄金のアイコンを探せ」（仮）。オーナーの「ストイックの脳内図」を、物語で使える形に書き直したもの。

## いまのストイック

- ストイックルーム（カセットの部屋）の主。学者。暴落の一晩を布で隠し、数える癖がある。若いころに「旋回」の決まりを書いた。論文『若きこののストイックの詳細な悩み』の書き手。
- 色の型：自分から「色を持たない者」（墨と灰）を望んだ。

## 若いころ：ガレージアイランドの詩人（前日譚）

- **ガレージアイランド**：ハニカムアイランドの隣にある謎の島。島の言葉は「自由」。
- 若いストイックは、まだ学者ではなく**詩人**だった。詩人としての純潔（自分の詩を売らない、名声と引き換えにしない、という誓い）を守っていた。
- 父が持つ**ガレージランド**の「酔いどれ草」（タバコのおどけた呼び名）の農園を訪ねるうちに、奇妙な冒険と騙し合いに巻き込まれていく。悪漢小説（ピカレスク・ロマン）や『千夜一夜物語』のような、夜ごとの語りと入れ子の物語。
- その冒険の合間に、彼は初めてコードを書く。のちの「旋回」の決まりの原型。**BA や PE たちが、そのコーディングの姿をそばで見守り、励ます**（遊べる形では、実況のチャットとして並ぶ）。
- 描き方の決まり：酔いどれ草は農園の景色として出すだけで、ストイックは吸わない。吸う場面や、それをかっこよく見せる演出は入れない（若い世代も遊ぶため）。
- 着想について：詩人が父のタバコ農園を訪ねて騙し合いに巻き込まれる、という骨組みは、ジョン・バースの小説『酔いどれ草の仲買人』（1960）への目配せ。小説の文章・人物名・筋はそのまま使わない。『千夜一夜物語』は古典として、語りの形（夜ごとの話、入れ子）だけを借りる。

## サトシパラメーター（ヘッダー）と OP

- **サトシパラメーター**：タイトル画面のヘッダーにある小さな計器。二つの顔文字 👮‍♀️ と 👮 がプレイヤーを見つめ、ときどきウィンクし、きらめく。「サトシ」はこの計器と、そこから生まれる顔文字の名前で、実在の人物ではない。
- **OP（ポップアップ）**：aviator が六つの「カセット星」を周回する。カセット星の形はオリジナル（実在のゲーム機のカセットの形は写さない）。最後に、計器の二つの顔文字から**サトシ顔**（顔文字のマスコット）ができあがる。

## トトシ中本とおもちゃの王国

- **トトシ中本**：かつての**おもちゃの王国**の王様。完全に架空の人物で、実在の人物（サトシ・ナカモトを含む）とは関係がない。
- 古いカセットの形をこよなく愛していた。けれど時代は変わり、量子のネットワークが「硬貨」の形をとって現れた。トトシ中本は、その新しい形を確かめるための旅に出る。
- いくつかのアニメーションの後、トトシ中本と、ヘッダーから生まれたサトシ顔（マスコット）が、二人でカセットのストイックルームを完成させる。

## 書き直した点（オーナーへの説明）

- オーナーの案では、サトシ・ナカモトの好み（「B 専」）や、成人向けの品物の王国が出てきた。サトシ・ナカモトは正体不明でも実在の人物なので、性的な好みや成人向けの品物と結びつけて描くことはしない。代わりに、トトシ中本を架空の**おもちゃの王国**の王にし、サトシはヘッダーの計器と顔文字のマスコットの名前にした。旅の目的（新しい「硬貨」の形を確かめる）と、二人でストイックルームを完成させる結末は残した。
