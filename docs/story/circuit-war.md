# サブストーリー「回路間戦争」（v0.1・2026-11-13）

「イーサリアムの黄金のアイコンを探せ」（仮）の外伝。量子の世界の裏側、カードスロットの中（ボクセルの心臓が鼓動している場所）で起きる戦い。本編 200 とは別の目次で進む。

## あらすじ

カードスロットの奥では、黄金の Ξ のアイコンがゆっくり回り続けている。島の機械フォン（ノイマン型）が、ある日そこへ一体の使いを送り込んだ。名乗りは一言。**"my name is o Herpo Death"**。

オー・ヘルポ・デスは、量子の状態をほどいてしまう「ノイズ」そのものの姿をしていた。触れた回路では、1 が 0 に、0 が 1 にひっくり返る（物理のバグ）。回るアイコンを守るため、PE たち（**PE 群**）は、変な砂で砦を築き始める。

砦の外では、アクティビスト双六の四つのチームが、それぞれの車の駒で回路の通りを走り回り、19 の骨のマスでニュースを拾い、三つのフィルター（事実・噂・感情）にかけて、どの回路を味方につけるかを競う。₿ チームの運転手ナギは、プロンプトチェスのナイトを操って、立体駐車場のような回路の階を跳ねていく。

戦いの終わりに分かるのは、オー・ヘルポ・デスが敵ではなかったこと。フォンは、砦がノイズに耐えられるかを確かめるために、彼を送り込んだ（テストのための攻め役、レッドチーム）。

## フィジカルアクティビスト（ルールの詳細）

アクティビスト双六とプロンプトチェスを一つの遊びにまとめた、体を使う版。

1. **盤**：回路の通り＝ 19 マスの骨（1/19 … 19/19）。各マスで回路のニュースが出る。
2. **三つのフィルター**：ニュースを 事実（忍耐）／噂（大胆さ）／感情（魅力）にかける。拾ったものは、そのマスの骨に残り、止まった運転手の性格を変える。
3. **コマンド**：手は `.sh` のコマンドとして書き、まとめて `git push` すると、全車が同時に動く。二台が同じマスに push したら「マージの衝突」で、両方動かない。
4. **ナイト**：ナギのナイトは、立体駐車場の 3D の桂馬跳び（2 マスと 1 マス、階も軸のひとつ）。手はプロンプトで書き、相手と同時に動く。同じマスに着いたら両方戻る。相手が去ったマスに着いても取れない。動かなかった相手に着いたら取る。
5. **体を使う**：プロンプトは声に出して読み上げる（読み上げた言葉どおりに動く）。読み上げが苦手な人は、書いて見せるだけでよい（聞こえない耳の物語と同じ決まり）。
6. **値段なし**：拾ったニュースや回路に値段はない。賭けもない。勝ち負けは「砦がノイズに何ターン耐えたか」で決まる。

## デフイヤーストーリーズ（聞こえない耳の物語）

- 音がなくても、物語の全部が伝わる章。ストイックの「音を消したテレビ」から生まれた考え方。
- 決まり：音はすべて文字と形で見せる（BA と PE の拍はチャットに文字で、オー・ヘルポ・デスの声は字幕で、心臓の鼓動は GIF の膨らみで）。音を出さなくても遊べる。
- 耳の聞こえない人を笑いの種にしない。この章は「音がなくても届く物語」を作る練習として置く。

## マーケティングに合わせるとき

- 実在の人物（経営者・学者・投資家など）を登場人物にしない。名前で宣伝の後ろ盾を借りない。
- 量子の台本や指紋の鎖のような「本当に動く仕組み」を見どころにする（嘘のない宣伝）。
- 値段・利回り・儲けの約束はしない。

## 書き直した点（オーナーへの説明）

- マイケル・セイラー氏は実在の人物なので、ナイトの運転手にはしなかった（宣伝に使うと、本人の推薦のように読まれる）。代わりに、すでにいる架空の運転手ナギ（₿ チーム）がナイトを操る。
- ホーキング博士は実在の人物なので、性的なものと結びつけない。代わりに、博士の名前がついた物理の考え（黒い穴の縁から少しずつ放射が出て痩せていく）を、砦の縁から砂が蒸発するしくみとして借りた。

## PE のミーム的な効果（2026-11-13 追記）

PE 群は、回路間戦争に向けて、ミーム的な効果（注目を集めて広がる力）を慎重に準備し始めた。決まり：注目は値段ではない。PE が増えると「どの駒が動くか」は変わるが、「どの駒が強いか」は変わらない。砦を厚くするのは、事実のフィルターを通ったニュース（ファンダメンタル）だけ。詳しくは `chess-wallstreet.md`。
