# 物語の地図 — 「イーサリアムの黄金のアイコンを探せ」（仮）

最終更新：2026-11-13。物語の文書が増えたので、全体を一枚にまとめた。細部は各ファイルへ。

## 骨組み

- 下敷き：シェイクスピア『テンペスト』（パブリックドメイン）。復讐劇の形で始まり、赦しと和解、若い世代の希望で終わる。
- 外枠（現在）：空き家になったエンジニアのガレージで、ストイックのカセットと北アイランド地方のカードが見つかる。沈められた黄金のアイコン（ハニカムの Ξ）を探す。
- 本筋（12 年）：ハニカムアイランドを追われたネフェリムと娘 Luna。島で 1 年に 1 章ずつ「サトシの書」を読み、返事の来ない手紙を瓶で流す。本土ではアリミノガールが瓶を見守る。12 年目の嵐で二冊目（表紙に黄金の Ξ）が届き、Luna が aviator をハックして塔の甲板に着陸し、旋回が止まる。
- 語り手：アリミノガール。色が巻き戻る（◀◀ REW）と過去、▶ PLAY で現在。
- 遊べる物語：`/mente/game/story`（プロローグ＋ 1 年目の 14 問まで。実況チャット・コンボ・豆知識つき）。量子の台本：`quantum/golden_icon_challenge.py`。
- 進め方：2 択か 4 択。物語 200 ＋ ミニゲーム 12。乱れたら Mente 式にそっと「アリミノボーイに聞く」、最後の面では Luna が一緒に操縦する。

## 決まり（物語全体）

- 実在の人物は名前と公の出来事だけ。姿・発言・内心を作らない。サトシの正体を推し量らない。
- 色の規則（統一）：型は 3 つ（暖色・寒色・色なし）。チャートは上げ緑・下げ赤。
- 点滅なし（毎秒 3 回以下）、動きを減らす設定に従う。
- 賭けの仕組み・値段・換金はない。ストイックの暴落は線の形と仕草だけ描き、相談先を載せる。
- 塔にぶつかる演出はしない（着陸）。Luna とストイックのあいだに色恋はない（Luna は子ども）。
- 他の作品のキャラクター・ロゴ・ブランド名は写さない（「アリミノ」は公開前に確認）。
