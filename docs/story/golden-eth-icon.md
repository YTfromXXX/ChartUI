# アニメーション「イーサリアムの黄金のアイコンを探せ」（仮）— あらすじの叩き台（v0.1・2026-11-13）

骨組みはシェイクスピア『テンペスト』（1611 年ごろ、パブリックドメイン）。復讐劇の形で始まり、赦しと和解、若い世代の希望で終わるロマンス劇。`{ }` は一緒に決める空欄で、`→` の後は叩き台の案。

## あらすじの概要（案）

ハニカムアイランドの正当な守り手ネフェリムは、地位を狙うリトルとストイックらの陰謀で、幼い娘 Luna と共に国を追われ、絶海の孤島に流れ着く。追放の小舟には、アリミノガールがこっそり書物と食べ物を積んでいた。その書物の中に、二冊の紙があった — 去った書き手の紙（サトシの書）と、後から来た読み手がそれを書き直した紙（ヴィタリックの書）。

12 年後、ネフェリムは書物から魔術を究め、杖の先に**黄金のイーサリアムのアイコン**（ハニカムの Ξ）を宿す。精霊エーリアルを使って嵐を起こし、リトルたちの乗った船を難破させ、自分の島へ漂着させる。

島では、ストイックの息子アリミノボーイと Luna が恋に落ちる。敵対者たちは幻に迷い、島のボアードエイプ達とぺぺ達は酒と陰謀で騒ぎを起こす。最後にネフェリムは復讐を越えて赦し、杖を折り、**黄金のアイコンを海の底へ沈めて**魔術を捨てる。ハニカムアイランドの地位と平和を取り戻し、島を離れる。

外枠：現在のストイックルーム。ストイックの「カセット」と、北アイランド地方の遊びのカードが、空き家になったエンジニアのガレージで見つかる。沈められた黄金のアイコンを探すのが、このアニメーションのタイトルの意味。

## 空欄の叩き台

- ストイックの占いが後に **{署名}** して **{ホワイトペーパー}** のように読まれる、のはもっと未来の話。
  → 占いは「予言」ではなく「署名された紙」として読み直される（鍵が示すのは書いた人ではなく、署名されたことだけ）。
- 名セリフ：「**{人間って}** なんて美しいんでしょう。これはすばらしい新世界…」
  → 原作どおり（ミランダの台詞）を推す。すぐ後のプロスペローの返し「おまえには新しいのだな」が、新しい世界を初めて見る若い世代と、それを知っている大人の対比になる。
  → 別案：「{鍵の持ち主たちって}」— チェーンの世界に寄せた言い換え。

## 遊びのカード（外枠の伝承）

- 北アイランド地方の遊びのカード（架空の地方。史実のタロットは北イタリアの遊びのカード）。占いとして読まれるのは 18 世紀末から — 史実のタロットと同じ年代にそろえる。
- 切り札 22 枚＝ 22 の場面（下の構想は 22 のうち最初の数枚）。

## 注意（決める前に）

1. **ボアードエイプ達／ぺぺ達**：Bored Ape Yacht Club は Yuga Labs の作品と商標、ぺぺ（Pepe the Frog）は Matt Furie の著作物（キャラクター）。名前も見た目も写せない。→ 役（島の住人・酔っぱらいの道化）だけ残し、オリジナルの名前と姿にする（例：「あくびザル達」「ケロ達」など、仮）。
2. **サトシ／ヴィタリック**：実在の人物。登場人物にせず、書物の書き手として名前だけにする（姿・台詞・内心を作らない）。サトシが現実に「不在の書き手」であることと、物語の中で書物だけが残ることが重なる。
3. **キャリバンの扱い**：原作の島の住人の描き方には、支配と差別の読みがある。島の住人を「笑いもの」や「仕える者」にしない描き方にする。
4. **「ファミコン」**：任天堂の商標。作中では「カセット」と呼ぶ（これまでの規則どおり）。
5. **Luna**：暗号資産の名前（2022 年に暴落したテラの LUNA）と同じ。偶然の一致として気にしないか、意図して重ねるかを決める。
