# ./LAB/library — 図書館

博物館（`./LAB/colorcube`）の隣。ページは `/lab/library`。

ジル・ドゥルーズとフェリックス・ガタリの共著 2 冊（『資本主義と分裂症』の 2 巻）を書誌情報として置く。

- 『アンチ・オイディプス』（L'Anti-Œdipe, 1972）
- 『千のプラトー』（Mille plateaux, 1980）

各概念の説明は ChartUI 用に書き下ろした一行の要約で、本文の引用は含まない。『千のプラトー』の 15 のプラトーは、ハニカム 7 マス（銀河 6 ＋ 特異点 1）の外を回る 15 のループ・マスに 1 つずつ対応させる（`books.ts` の `PLATEAUS`）。
