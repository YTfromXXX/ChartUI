# ./LAB/colorcube — 色彩の出現と鋼板の博物館

より写実的な UI 描画テクニックを研究するラボ。ページは `/lab/colorcube`。

## 1. 色彩の出現（`emergence.ts`）

方眼紙の上に、水のような規則性で色が現れる手順を 11 の動詞（to lay, to drop, to pair, to wave, to spread, to wash, to cut, to fold, to scatter）として規則化する。プロセスそのものが形を決める、というリチャード・セラ的な考え方に倣った。

| 規則 | 内容 |
| --- | --- |
| 波長 | 最初の一滴の列 c₀ が波長 λ。双子の流れは 2 列隣（偶数間隔の対）、次の波は 2λ 先（列 3c₀） |
| 交差 | 横の広がりは第 2 波を覆い、第 1 波との交差点だけを白く洗い流す |
| 切断・折れ・散布 | 遠い流れを白・黒・白で切り、中心で三角の星が折れ、聴診器（Cure）が流れの下流に群れる |

seed 0 は添付の研究シート（48×36 マス：緑 9・11 列、青 27 列、横帯 7–8 行）を再現する。seed を変えると同じ規則のまま位置が揺らぐ。

## 2. 仮想 UI「Name OS」（`nameOs.ts`）

UI を先に設計せず、出現した層を同じ順に読み取って Linux 系の窓システム部品にする：方眼＝デスクトップ、第 1 波＝ドック、第 2 波＝分割線、横帯＝トップパネル、洗われた交差＝ランチャー、黒セル＝ターミナル、星＝アプリメニュー、聴診器の群れ＝デスクトップアイコン、単独記号＝通知トレイ。各部品は Cure Kit の 1 項目が受け持つ。

## 3. 博物館（`museum.ts`, `SerraPlate.tsx`）

骨格棟 19 室＋内部棟 3 室。1 室に 1 枚の耐候性鋼板（slab / arc / torqued / prop / spiral）。平面曲線とねじれた上端の間に罫線面を張る小さな 3D レンダラで、次の写実技法を研究する：

- ランバート陰影（面法線と光源の内積）
- 画家のアルゴリズム（奥から手前へ描画）
- 錆の乱流（`feTurbulence` を板の形で切り抜いて重ねる、酸化度で濃度が変わる）
- 落ち影（底辺を光と反対側へ押し出してぼかす）
- 上端の鏡面リム

## 4. 双六（レトログリッド A / B）

二次元上では、出現の順を追う双六になる（`app/cure-api/TSMonsterEngine/SugorokuKit`）。22 マス＝Kit、6 面ダイス＝ハニカムの 6、偶数マスは次の奇数マスへ滑る（奇数回帰、空いた偶数マスが特異点）、奇数マス 11 個が出現の 11 段に対応、22 を越えると新しい seed で次の周回（無限ループ）。
