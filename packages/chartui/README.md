**22 angles, one glass box — geometry and design rules for market charts.**

The geometry, colour rules and file formats behind **ChartUI**: a 22-angle glass box for market charts, knots read from candlesticks, signed mesh pointers, and design rules you can check with code. No runtime dependencies, works in the browser and in Node.

```bash
npm install chartui
```

```js
import { strip, knots, ladder, meshmeta, colour, glass, slots, fx } from 'chartui';
```

## Why 22 angles

ChartUI films one glass box from **22 camera angles** (`glass.cameraAngles`). Every angle owns one slot, so a view of the box is a strip of 22 coefficients — two rows of 11:

```
◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|
◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|
```

## The zero that remains when the separators go

Data science keeps meeting coefficients nobody has measured yet. On the internet they appear as missing bytes in a fixed-width cryptographic field; in the physical world, as a sensor that has not reported.

- **While the `|` separators are there**, a slot can stay blank (`◻︎`) and every other slot keeps its place.
- **Delete the separators** and the blanks disappear: `1|◻︎|3` collapses to `13`, and nobody can tell it from `1|3`. A placeholder, **0**, is what keeps the positions. Positional numerals needed a zero for the same reason.
- **But a placeholder must never be read back as a measurement.** So `chartui` keeps three states — `◻︎` unknown, `0` measured zero, `n` a value. When it packs a strip without separators, it writes every slot and returns a mask of which zeros only hold a place.

```js
const cells = strip.parseStrip('1|◻︎|3|◻︎|◻︎|0|◻︎|◻︎|◻︎|◻︎|◻︎|\n◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|◻︎|');
strip.collapse(cells);        // "130"  — positions lost
const packed = strip.pack(cells);
packed.digits;                // "1030000000000000000000"  — positions kept
strip.unpack(packed);         // [1, null, 3, null, null, 0, ...] — unknowns come back as unknown
strip.slotAngle(5);           // which camera angle slot 5 belongs to
```

## Modules

| Namespace | What it does |
|---|---|
| `strip` | The 22-slot strip: parse, format, pack without separators, map a slot to its camera angle |
| `glass` | The glass box (edges 1 : r : r², golden φ or Yamato √2), price paths that hug its side faces, forecast scoring, 22 camera angles |
| `knots` | Counts crossings of a drawn curve (the same counter as the Python package) |
| `ladder` | Cube ladder: 8 candles per glass cube, one knot per cube (coil, hitch, loop, bend, stopper, figure-eight), knot prediction |
| `meshmeta` | Mesh parts, best triangles A–D, `.meshmeta` byte pointers into an STL, Ed25519 signature check |
| `colour` | Golden (ink & indigo) and Yamato (flame & wax) palettes generated by rule, contrast checks, candle-spring melt rate from volume and volatility |
| `slots` | Card slots: what a metal cylinder does in a rope slot, mass face-down insertion with an animation-lane cap |
| `fx` | Which way a currency pair points against USD (EURUSD −1, USDJPY +1, JPYUSD −1) |

## Design rules (checked in code)

- No flashing above 3 Hz; flicker ≤ 2.5 Hz and ±8 % brightness.
- Text contrast ≥ 4.5 : 1. Price lines and accents ≥ 3 : 1 against the background and the smoke.
- Neighbouring hues ≥ 90° apart.
- `colour.checkEdition('golden')` returns the numbers so a page can show them.

## Works with Python

`meshmeta.verifyMeshmeta` checks signatures made by the Python package [`cure-oracle`](https://pypi.org/project/cure-oracle/) (`cure meshmeta in.stl out --key key.pem`).
